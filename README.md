# ✨ Personal Gemini Chatbot

> An AI-powered conversational chatbot built with **Python, Streamlit, and Google Gemini API**.

A simple and modern web-based chatbot that allows users to interact with Google's Gemini AI through an intuitive chat interface. The application maintains conversation history during the active session and is securely deployed using Streamlit Community Cloud.
